# Installation Guide

## Prerequisites

- Windows: PowerShell 5.1+, Python 3.10+, Git, MuMuPlayer (official), rooted Android with Google Play + Google One.
- macOS: Terminal, Python 3.10+, Git, `android-platform-tools`, rooted Android environment.

## One-command install

Windows:

```powershell
git clone https://github.com/the-anonyyy/google-ai-verify.git && cd google-ai-verify && .\run-all.ps1
